## 🌟 What is Stoic Body Community Starter?

**Stoic Body Community Starter** is an open-source, privacy-first physical training and daily discipline application designed for anyone who wants an elite, clean-slate training system on their desktop or browser.

Unlike bloated subscription apps with mandatory cloud tracking, Stoic Body runs **100% offline and locally on your machine**. 

### 🛡️ 100% Clean Slate Guarantee
- **Zero Pre-logged Workouts**: Fresh database ready for your personal PRs and training journey.
- **Zero Private Meal Logs**: Uncluttered macro ledger ready for your personal nutrition.
- **Zero Hardcoded Developer Schedules**: Start fresh with customizable routines or create your own daily milestones.
- **Zero Ads, Zero Tracking, Zero Accounts Required**.

## 👥 Multi-Athlete & Family Profile Isolation

Built so partners, spouses, or roommates can use the same desktop app without cross-contaminating data:

- **1-Click Profile Switcher**: Switch instantly between profiles from the top navigation bar.
- **Complete Storage Partitioning**: Each athlete profile maintains its own isolated training history, personal records (PRs), meal logs, body measurements, and custom routines.
- **Preconfigured Profiles**: Ships with `Sophia (Aurelia)` and `Marcus (Spartan)` starter profiles, or create unlimited custom profiles.

## 🚀 Quickstart Desktop

### Prerequisites
- [Node.js](https://nodejs.org) (v18 or higher)
- Git

### Installation & Run

```bash
# 1. Clone the clean community repository
git clone https://github.com/Stoic-EmpireLabs/stoic-body-community.git

# 2. Enter directory
cd stoic-body-community

# 3. Windows 1-Click Launch (or run npm install & npm run dev)
./run-desktop.ps1
```

Or manually using npm:

```bash
cd web
npm install
npm run dev
```

Visit `http://localhost:5173` in your browser. You can install it as a **PWA (Progressive Web App)** on Chrome, Edge, Safari, iOS, or Android by tapping **Install App** in your browser's address bar.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Build System**: Vite 6
- **Styling**: TailwindCSS 3.4
- **State & Local Persistence**: Zustand + LocalStorage Engine with Snapshot Isolation
- **Icons**: Lucide React
- **Audio Engine**: Web Audio API Sound Synthesizer (offline ticks & bell cues)
